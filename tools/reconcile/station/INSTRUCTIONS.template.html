Weigh station: flash and reconcile

Everything here runs in Chrome on the studio PC (or any Windows PC). Nothing to install. This kit:

Firmware{{BUILD}} (commit {{COMMIT}}), {{SIZE}} bytes
eSUN cataloguestation-catalogue.json: {{CATCOUNT}} orderable items from esun3d.com, {{CATDATE}}
Decisions{{DECISIONS}}: {{MERGES}} merges, {{RENAMES}} renames, remove test vendor(s) {{VENDORS}}

Copy the whole kit folder from the thumb drive to the PC's Desktop first.

0. Check the firmware file (optional, 1 minute)

  1. Open the kit folder, click the address bar, type cmd, press Enter.
  2. Type certutil -hashfile firmware.bin SHA256 and press Enter.
  3. It must print {{SHA256}} (also in SHA256.txt). If not, copy the kit again.

1. Back up the station

  1. In Chrome open the station (its address, or http://weighstation.local).
  2. Administration → Backup → Download both the log and the config. Keep them.
  3. Note: number of spools on Inventory ____, products on Administration → Products ____, this month's Usage total ____ g, and one spool you can weigh (# ____, ____ g).

2. Flash the firmware

Nobody weighing. The station is down for a couple of minutes.
  1. Connect the PC to the station's panel USB-C port with a data cable.
  2. In Chrome open https://espressif.github.io/esptool-js/ (Espressif's own web flasher).
  3. Under Program, leave Baudrate as it is and click Connect. Chrome lists serial ports: pick the one named like USB JTAG/serial debug unit (or the new COM port), click Connect. The page shows the chip: it should say ESP32-S3.
  4. In the flash table: Flash Address = 0x10000, and choose firmware.bin from the kit folder. One row only.
  5. Click Program. Wait for it to finish (about a minute or two).
  6. Click Disconnect, then restart the station: unplug its power for five seconds and plug it back in.
Never click Erase Flash, and never write anything at any address but 0x10000: the station's data (log, Stock List, settings) lives in the rest of the chip.

The display comes back green: "Seattle Makers / Place spool to begin". (Orange "Join WiFi" means it didn't rejoin the network; see the manual.)

Check: the counts from step 1 match; the menu reads Inventory · Reorder · Restock · Usage · Administration; weigh the noted spool, remaining is the same within a few grams; Restock → Or enter manually refuses to save until This is a new product is ticked. Reorder now lists an item once it's below half its target. Download another backup (Administration → Backup).

3. Load the eSUN US catalogue

  1. On the station: Administration → Station setup → eSUN US catalogue.
  2. Click Choose file, pick station-catalogue.json from the kit folder, click Load catalogue file.
  3. It says eSUN US catalogue loaded: {{CATCOUNT}} items. Nothing else on the station changes.

Check: put a new spool's tag on the scale (or open Restock with one already on), choose + New product…. Under Search filament catalog, the vendor list starts with eSUN — eSUN US catalogue. In Or enter manually, choosing the eSUN vendor lists eSUN's own materials and colours. Both work without internet.

4. Reconcile

Nobody at the scale for the few minutes this takes.
  1. In Chrome, on any page of the station (not the flasher), press F12 and click the Console tab.
  2. Open reconcile.js from the kit folder in Notepad (right-click → Open with → Notepad), Ctrl+A, Ctrl+C.
  3. Click in the console, Ctrl+V, Enter. The first time, Chrome refuses and asks you to type allow pasting: type it, press Enter, then paste again and press Enter.
  4. It checks only and prints what it would do. It must end in green Checks passed. Red SKIP lines name anything that changed since the decisions were made; those are left alone. If it says the firmware doesn't match, do step 2 first.
  5. Type reconcile.apply() and press Enter. When Chrome asks whether the station may download multiple files, click Allow.
  6. It must end in green Result checks out and Done. Your Downloads folder now has four new files: the backup before and the backup after.

Then: on Administration → Products the names read like PLA Basic Black, PETG Black, PLA Silk Mystic …; no {{VENDORS}} products; Reorder has no "not linked" items. Erase the test spools' tags (Administration → Erase Tag) or bin them, or the station adopts them back when they're placed. Each spool's tag picks up its new name by itself the next time it's placed.

If something goes wrong

  • The flasher can't connect / no port listed: try another cable (some only charge) or port. The station keeps its old firmware until a flash completes.
  • The reconcile prints red FAIL or PROBLEMS: stop. Restore the before-reconcile files from Downloads (Administration → Backup → Restore, log then config) and bring them to Claude.
  • Something looks wrong after the flash: prefer fixing forward with Claude. To go back, the old firmware has to be built on the Mac (commit d99c83b), then restore the backup from step 1.
  • Reboot loop or blank screen: lift the spool off the scale and power-cycle.
