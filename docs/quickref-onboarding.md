# Quick Reference — Onboarding a New Spool

*Print this page and keep it at the station. Full detail: [user-manual.md](user-manual.md).*

## Steps — for each new, untagged reel

1. **Stick an OpenPrintTag sticker** on the flat hub face, centered. Press firmly.
2. **Place the spool on the scale.**
3. The display counts down from 2 ("New tag found / Remove to cancel").
   **Remove the spool** to cancel; **leave it** to register.
4. The display shows **"Registered! Spool #N / NEEDS DETAILS"**. Open the
   **Restock** page (or scan the QR code with a phone). Keep the spool on the
   scale.
5. **Say what it is**, in this order:
   - **Scan the box's barcode** (press the scanner's trigger), before or after
     placing the spool. A known barcode picks the stock item for you.
   - **Or pick it under "Which stock item is this?"** Type to search the
     Stock List. Greyed items aren't linked yet; tell an admin.
   - **Not a stock item?** Pick it under **"This spool is…"** (type to filter).
   - **New product?** Use the catalog search, or **Or enter manually**.
6. **Set the tare** (required): pick a **spool profile**, type it, or put an
   empty spool of the same type on the scale and press **Capture tare**.
7. **Cost** (optional): type what the reel cost. Blank keeps the current
   price; `0` clears it.
8. Press **Save & write tag.** First check **"Barcode … will be recorded
   for …"** above it: right only if you scanned *this* box, else press
   **clear**. If Save asks about a barcode, the scan and the pick may not match.

**Next spool:** place it. The page moves to it.

**Vendor tag already on it?** Just place it. **Already onboarded?** Click
**Change this spool's details** to edit it.

## If it goes wrong

**Don't rewrite station tags with the Prusa app.** It retires the spool.

**"Read Error" after a failed registration:** on **Administration → Erase Tag**,
press **Start erase mode**, place the spool, press **Stop erase mode**, place it again.
