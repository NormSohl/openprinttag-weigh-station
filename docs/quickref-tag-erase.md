# Quick Reference — Tag Erase

Erases every tag placed on the scale while erase mode is on.

**Erase only tags from finished spools.** Erasing retires the spool.

## Steps

1. Open `http://weighstation.local/erase`.
2. Press **Start erase mode** and confirm. The station screen shows
   **ERASE MODE** in red.
3. **Place a spool.** It's erased at once. Wait for **"Tag erased"**.
4. **Remove it** and place the next one.
5. Press **Stop erase mode** when done.

Erase mode turns itself off after 10 minutes with no tag placed.

**While erase mode is on, any tag placed is erased**, including a spool you
meant to weigh.
