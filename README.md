# Filliment-Scale-with-OpenPrintTag-RFID-tracking-and-Spoolman-integration
This is the firmware for the scale project. the project is intended to serve Seattle Makers.
the scale is designed to complement spoolman and automate adding new spools (still need data entry in spoolman) and periodically weighing spools. Promethius is used to maintain history.
